# 可选的设计参考（仅用户另行要求时）

v1.2.0起，查设计网站和先生图都不是默认步骤或门禁。正常流程为严格澄清需求、确定方案、逐页规划、制作及验收。本文件只在用户明确要求找参考或做视觉小样时使用；不能据此恢复旧版必经流程。

先看用户提供的图片、旧稿、指定卖家和配色，再找 PPT 代做团队的案例内页、模板卖家售卖详情的多页拼图与改稿对比。实际浏览画面，记信息密度、标题层级、区域比例、图形关系、图表与表格组合、主辅色、渐变与阴影用途。用户参考优先于助手个人审美，不得擅自改成极简。

优先商业案例入口：

- 锐普案例：https://www.rapidesign.cn/case.html
- 锐普政府汇报展示：https://www.rapidesign.cn/government-report.html
- 梳理 PPT 案例区：https://shulippt.com/
- 西略会议／汇报案例：https://www.cqxilue.com/h-col-115.html
- 设计师自己发布的站酷／小红书／哔哩哔哩作品和售卖页；核实具体作者、作品与链接，查不到原帖就写“原帖未核实”，不编造店铺地址。

检索式可用“PPT定制 工作汇报 案例”“PPT模板 经营分析 售卖 展示”“PPT改稿前后 项目复盘”，加配色和图形结构。封面、网站装饰和搜索标题不能代替内容内页。售卖图的外层广告、样机和价格不属于幻灯片画布。

常见模板站仅作场景补充，不替代商业实例：

- iSlide：https://www.islide.cc/ppt
- 优品 PPT：https://www.ypppt.com/ ；黑白商务实例：https://www.ypppt.com/article/2017/4415.html
- Slidesgo：https://slidesgo.com/
- SlidesCarnival：https://www.slidescarnival.com/
- Pitch：https://pitch.com/templates
- PresentationGO：https://www.presentationgo.com/

网站可用性会变化。遇到空白、拦截或只有文字结果，不能记为已看过设计；换可访问的具体例子或使用用户给的截图。网站模板的版权与下载许可独立核对，不能因为能看见就复制整套模板分发。

建议的观察记录：

```json
{"url":"实际作品页面","accessed_date":"YYYY-MM-DD","visually_inspected":true,"observations":"具体看到的排印、留白和图文比，以及为何适合本任务"}
```

若用户还要求生图，再写提示词：任务与受众、单页内容、参考文件、借鉴范围、布局与字号关系、图片或图表边界。输出平面16:9幻灯片，不带售卖外框。用真实文字和必要数据示例；合成示例必须标识，图像只是视觉预览，不是可编辑PPT或真实证据。先做少量代表内容页供判断，未认可前不批量生成三十套。若被否定，记录反馈并更换图形组织与参考，不能只换色。

本轮用户参考涵盖蓝白甘特与项目复盘、黑红经营看板、红白企业汇报、蓝白／红金立体图解、分层圆环与战略平台。配色和图形组织一起借鉴，不能压缩成同一种三卡片。渐变、阴影、立体台座、圆环、色块与卡片均允许按内容使用，不一概排斥或无关堆砌。认可后拆成原生文字、形状、图表与必要图片，并做同版渲染和编辑检查。
