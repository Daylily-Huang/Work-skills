# 本包使用的参考与第三方资源

用户指定 `editable-research-ppt` 为参考。本包复用其 MIT 许可的 `assets.py`、`render_powerpoint.ps1`、十套配色配置和许可允许的素材缓存，不复用其科研专用接单门禁。参考版权与许可全文在 `references/reference-MIT-LICENSE.txt`；原始声明归档在 `references/reference-third-party-notices.md`，其中提到的完整原包字体、动画和科研模板并非全部随本包提供。

本包的三十套六页模板及其生成器为本项目新制作。模板中所有数值、人物、任务与论述均为明确标识的合成示例，不包含用户真实研究或业务资料。网页设计参考只用于理解一般排印原则，未下载、复制或再分发 iSlide、优品、Slidesgo、SlidesCarnival、Pitch 等网站的模板文件和页面截图。

`assets/media-library/catalog.json` 逐项记录 SVG 的原始作者、固定提交、源 URL、路径、哈希与许可；原生缓存另记路径及哈希。SVG 与缓存不是两项不同素材。Lucide 为 ISC，授权文件列明的 Feather 衍生图标为 MIT；Tabler 为 MIT，Maki／Temaki 为 CC0，Bioicons／Servier 按项目逐项 CC0 或 CC BY，Noto 插图按其 Apache 2.0 许可。不能把它们统一改称本项目 MIT。

完整第三方许可在 `assets/media-library/licenses/`。使用 CC BY 图时保留页面可见署名与来源；资料中的真实照片、企业标志、论文图和数据仍须按各自权限处理。原生缓存的历史编辑标记不是本项目对所有软件的兼容保证。

本包不含商业字体，不含 PowerPoint、Excel、Python 或第三方 Python 库本体。运行依赖见 requirements.txt，Office 软件由使用者自行提供。
