# 需求与内容判断

## 需求定位：何时必须问

先检查用户已经给出的信息。下列信息若影响实际内容却无法从材料确定，主动问具体问题：

- “给学生上课”与“给评委说课”不清楚：两者面对的听众、内容和叙事不同。
- 年级或已有基础不清楚，而同一主题存在明显不同难度。
- 本课究竟重理解、应用、纠错还是应试不清楚，且会改变讲解与练习。
- 要按指定教材/课标，但版本、章节、原文不齐；材料相互冲突；题干缺条件。
- 要做整节课，但课时未知；或者页数、时长和内容要求互相挤压。

问题要落在分叉上，例如：“这份是给八年级学生上新课，还是给评委介绍你的教学设计？”不要把整张需求表丢给老师。页码标记、装饰位置等不必停下来问；用户授权建议页数/时长时，给合理建议并记录授权依据。任何情况下，沉默或时间经过都不是回答。

`brief.ambiguities` 记录模型识别的重要歧义。脚本只能拦已记录的未答问题和可识别必填缺口，不能自动发现全部语义分叉。

## 教学内容：按本次目标组织

| 用途 | 优先判断 | 常见组织线索 |
| --- | --- | --- |
| 新授 | 学生在哪一步不理解 | 从现象/例子推进到概念，再看能否用于新情境 |
| 复习 | 哪些联系或差异容易混淆 | 对比、知识联系、少量诊断题和方法归纳 |
| 习题讲评 | 错在条件、概念还是步骤 | 有代表性的错误、判断依据、改法与迁移题 |
| 说课 | 为什么这样教 | 学情与目标的联系、设计依据、活动与评价的对应 |
| 大学课程 | 概念关系、前提和应用边界 | 真实问题、解释/推导、案例与讨论，按基础调整 |
| 局部修改 | 用户要求改哪些内容 | 在原稿中窄改；不借此重做全套教学设计 |

这些不是规定页序。学情信息不足时用可确认的学生基础说明设计，不编班级调查结果。目标写成学生能做什么，活动让学生实际观察、比较、解释、表达或解题，检查方式对应目标，不堆“知识、能力、情感”通用空话。

课件与讲稿分工：学生页呈现问题、材料、关系和必要结论；较长讲解、答案、追问与观察要点放教师备注。保持学生页有可读的实质内容，不能把一切都塞进备注让投影只剩口号。

## 事实、引文和答案

用户材料优先；对齐指定原文时核到实际页/段。需要外部知识或现行课标时查适用的原始/官方来源，不引用搜索摘要冒充原文。数学题独立复算，检查条件、单位和极端情况；开放题给理由或评分要点，不伪装成唯一标准答案。来源记录留在计划和备注，除引用/许可需要外，不反复在学生页加免责声明。

只有确需数据图表时使用图表。模板中的 48/32/20 等值是版式样例，必须替换。示例数据需用户允许，并在该页用“示例”等短标记区分；真实数据对应具体来源。数据缓存与“编辑数据”工作簿应一致。

## 文风与视觉

- “圆柱侧面放在桌面上可以滚动”比“圆柱在某些情况下或许具有一定滚动特性，仅供参考”更适合课堂；必要条件明确保留，不绕开判断。
- “找出支持你判断的词句”比“全面提升核心素养、构建高效课堂”更有教学信息。
- 不把“仅供参考”“无法保证”“请自行核实”作为常驻页脚。讲授这些词本身或引用他人文本时可以出现，结合语境判断。
- 不是禁用“可能、建议、通常”等词。科学不确定性、教师建议和条件判断要按实际语义表达，避免词表误杀。
- 模板根据内容和视觉场景选配：`T01`–`T12` 面向说课、教研与学情数据分析（含固定说课导航与图表/表格页）；`T13`–`T20` 面向课堂新授、提问讨论、活动与记录，底图为全页插画。选模前须检查 `visual_scene` 与 `avoid_for`，避免插画里的具象物件（如植物放大镜、几何积木画本、立体教具、低龄红领巾）与课文或学科冲突；通用讨论课优先用 `T19`、`T20` 等无特定学科器物限制的模板。
- 大问题适合留白，比较适合并置，过程适合顺序，作品/证据适合图文说明。不要每页三卡片，不要求每页都有卡通，也不把高年级做成黑金科研报告。
- 插画要与背景自然相接，照片用有意图的取景或相框；保留人物完整、比例和画风一致。不能靠加白框掩盖截图残边。

## 脚本与模型分工

脚本管：已知缺口、未答重要问题、必讲点覆盖、目标/活动链接、活动时长下限（整节课不少于半课时）、字段与表格/图表数据完整、占位提示与典型未替换字样拦截、框高行容与跨页重复/混搭风格提示、文件关系和当前版本绑定。模型管：是否存在尚未记录的重要歧义、内容取舍是否合适、知识/答案是否正确、文字是否自然、插画意象与页面美感是否协调。检查通过不等于教学效果已被证明。
